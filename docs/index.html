English

This is the update repository for the SuperNOVA game console (Fedora bootc) and related projects.

Repository file

curl -fsSL https://repo.example.org/supernova.repo -o /etc/yum.repos.d/supernova.repo

Or open it directly: supernova.repo

In your bootc image (recommended)

Add this to your Containerfile:

RUN curl -fsSL https://repo.example.org/supernova.repo -o /etc/yum.repos.d/supernova.repo
RUN dnf install -y PACKAGE

On a running console (temporary until reboot)

sudo dnf install --transient PACKAGE

Check the repository

dnf repolist
curl -fsSI https://repo.example.org/x86_64/repodata/repomd.xml

Architectures

  • x86_64: /x86_64/
